# 약사 검수 결과 (1차, 2026-10-18 · v2.19에서 반영)

OMNI-PHARM v2.18.0의 판정을 약사 2명의 블라인드 판정과 비교한 첫 외부 검증입니다. 약사는 프로그램 판정을 보지 않고
`약사_검수표_배포용.xlsx`의 200개 사례(환자 6유형 × 흔히 쓰는 약 2~4개)를 판정했습니다. 채점: `scripts/score_review.py`
(`logs/validation/review_score.json`, 불일치 사례 `logs/validation/review_disagreements.csv`). 검수자 이름은 문서에 적지 않습니다(약사 A·B).

## 1. 수치

| | 약사 A | 약사 B |
|---|---|---|
| 판정한 사례 | 200 | 200 |
| 약사 판정 분포 (위험/주의/안전) | 69 / 85 / 46 | 108 / 72 / 20 |
| 프로그램과 일치율 | 55% | 43% |
| Cohen 카파 (선형 가중) | 0.32 (0.39) | 0.19 (0.24) |
| '위험' 민감도 — 약사가 위험이라 한 것을 프로그램도 위험이라 한 비율 | **45%** (31/69) | **31%** (33/108) |
| '위험' 양성 예측도 — 프로그램이 위험이라 한 것을 약사도 위험이라 한 비율 | 82% (31/38) | 87% (33/38) |

- 프로그램 판정 분포: 위험 38 · 주의 90 · 비교적 안전 72.
- **약사끼리의 일치도: Cohen 카파 0.44**(Fleiss 0.42, 중간 수준) — 프로그램이 도달할 수 있는 현실적인 상한입니다.
  프로그램과 약사의 카파(0.19~0.32)는 이보다 낮습니다.
- 두 약사가 같은 판정을 한 128건 중 프로그램이 같은 판정을 한 것은 70건(55%).
- 두 약사가 모두 '위험'이라 한 66건: 프로그램 위험 30 · 주의 26 · **안전 10**.
- 프로그램이 '위험'이라 했는데 약사가 '안전'이라 한 사례는 0건입니다. 오류는 거의 모두 **과소 판정** 방향입니다.
  (v2.18에서 경고 피로를 줄인 것과 반대 방향의 문제가 드러남)

## 2. 두 약사가 모두 '위험'인데 프로그램이 낮게 본 36건의 원인

| 원인 | 건수 | 예 |
|---|---|---|
| 간질환(간경변)에서 쓰면 안 되는 약 | 10 | 메트포르민, 스타틴(활동성 간질환 금기), NSAID, 발프로산, 이소트레티노인, 리바록사반 |
| 소아 연령 금기 | 8 | 트라마돌(12세 미만), 퀴놀론(18세 미만), 졸피뎀, 이소트레티노인, 아스피린 |
| 임신 중 피해야 할 약(DUR 임부금기 2등급 포함) | 7 | 글리메피리드, 퀴놀론, NSAID, 리바록사반, 다파글리플로진 |
| 중증 신기능 저하(CrCl 18.5)에서 금기 | 6 | 리튬, 스피로노락톤, 둘록세틴, 리바록사반+베라파밀 |
| QT 연장 병용금기 | 3 | 에스시탈로프람 + 클래리트로마이신·아미오다론 |
| 기타 | 2 | 신기능 저하 + 콜히친 + 베라파밀, SSRI 2종 중복 + 간경변 |

**36건 중 31건은 약끼리의 상호작용이 아니라 '이 환자에게 쓰면 안 되는 약'**(간·신장·임신·소아)입니다.
프로그램의 약물-질환 규칙이 신기능·간기능 수치에 따른 금기를 거의 다루지 않고(메트포르민 CrCl<30, NSAID 정도),
식약처 DUR 임부금기 2등급을 모두 '주의'로, 제형이 정해진 DUR 연령금기를 성분만 입력하면 '주의'로 낮추기 때문입니다.

## 3. 프로그램이 두 약사보다 높게 본 7건
대부분 허가 문서 근거가 있는 판단 차이(트라마돌+프레가발린, 시프로플록사신+도네페질 등)이지만, **저용량 아스피린을 심부전·신기능
저하 환자의 '소염진통제 금기'로 본 것**(#23)은 프로그램 오류입니다. 신기능 '금기'가 CrCl 60 미만에서 걸리는 것도 기준(Beers: 30 미만)보다
넓습니다.

## 4. v2.19 수정과 재채점 (같은 200건 — 개발 세트이므로 독립 평가 아님)

1차 결과의 원인별로, 사례가 아니라 **허가사항·지침의 일반 규칙**으로 고쳤습니다(규칙마다 출처: `src/omnipharm/rules/*.json`).
- 간경변·활동성 간질환(간질환 + 빌리루빈 ≥ 2 mg/dL 또는 아미노전이효소 ≥ 3배): 스타틴, 메트포르민, NSAID, 발프로산 등 간질환 금기 약,
  경구 레티노이드, 경구 항응고제(DOAC) — 금기
- 중증 신기능 저하(CrCl < 30): 리튬, 칼륨 보존 이뇨제, 둘록세틴, 다비가트란, 설포닐우레아, 칼륨 제제, 니트로푸란토인, NSAID — 금기,
  Xa 억제제 — 주의. NSAID 금기 기준을 CrCl 60 미만 → 30 미만으로 바로잡음(30~59는 주의)
- 임신: 설포닐우레아, 퀴놀론계, DOAC, SGLT2 억제제, NSAID(저용량 아스피린 제외) — 금기(대체약이 표준인 약)
- 소아: 성분만 입력해 제형을 모를 때 식약처 DUR 연령금기의 제형에 일반 정제·캡슐이 있으면 금기로 적용(분무제·주사제만이면 제외),
  이소트레티노인 12세 미만 금기
- 에스시탈로프람·시탈로프람 + TdP 위험이 가장 큰 QT 연장 약(Ia·III군 항부정맥제, 마크롤리드 등) — 높음. 모든 QT 약으로 넓히자 기존
  개발 감사(에스시탈로프람+쿼티아핀 = 주의)와 어긋나 좁힘
- 조건부 규칙(신규): 신장·간 기능 저하 + 콜히친 + P-gp/강한 CYP3A 억제제, 신장 기능 저하 + 리바록사반 + P-gp·중등도 CYP3A 억제제 — 금기
- 저용량 아스피린을 심부전·신장·고혈압·심장질환의 NSAID 경고에서 제외(1차 #23 오류)

| | 약사 A (전 → 후) | 약사 B (전 → 후) |
|---|---|---|
| 일치율 | 55% → 68% | 43% → 69% |
| Cohen 카파 | 0.32 → 0.52 | 0.19 → 0.51 |
| '위험' 민감도 | 45% → 97% | 31% → 76% |
| '위험' 양성 예측도 | 82% → 78% | 87% → 95% |

두 약사 모두 '위험'인 66건: 프로그램 위험 30 → 66. 두 약사보다 높게 본 사례 7 → 5. **이 수치는 이 200건을 보고 고친 뒤의 값이라 성능의
근거가 아닙니다.** 고친 규칙이 처음 보는 사례에서도 맞는지는 2차 검수(새 사례 200건, #201~400, 새 환자 7명 — 중등도 신장저하·
지방간처럼 규칙이 넓게 걸리면 과다 판정이 드러나는 환자 포함, 1차에 없던 약이 든 사례 142건)로 잽니다:
`docs/validation/약사_검수표_2차_배포용.xlsx`.

같은 수정 뒤 다른 기준: 임상 감사 109/109·60/60·18/18·22/22 그대로, 식약처 DUR 시험 절반 그대로(55.3%/77.3%), 음성 대조군 거짓 경고 3%
그대로, 실제 처방 1,500건 위험 12 → 13%, AGS Beers 위험 42 → 33%(전에 '위험'이던 10건 중 2건은 CrCl 30~59에서 NSAID를 금기로 본
잘못된 이유였음).

## 5. 2차 검수 — v2.19의 독립 평가 (2026-10-18, 새 사례 200건 #201~400)

같은 약사 2명이 1차와 겹치지 않는 새 사례(새 환자 7명, 1차에 없던 약이 든 사례 142건)를 블라인드로 판정했습니다. **v2.19 규칙을
만들 때 보지 않은 사례**이므로 이 표가 v2.19 성능의 정직한 수치입니다(`logs/validation/review_score_v2.19.0.json`).

| | 약사 A | 약사 B | 1차(v2.18) A / B |
|---|---|---|---|
| 약사 판정 분포 (위험/주의/안전) | 66 / 90 / 44 | 104 / 78 / 18 | |
| 일치율 | 64% | 48% | 55% / 43% |
| Cohen 카파 (선형 가중) | 0.46 (0.53) | 0.25 (0.34) | 0.32 / 0.19 |
| '위험' 민감도 | **61%** (40/66) | **45%** (47/104) | 45% / 31% |
| '위험' 양성 예측도 | 82% (40/49) | 96% (47/49) | 82% / 87% |

- 약사끼리의 카파 0.48(Fleiss 0.47). 프로그램과 약사 A의 카파(0.46)는 이 상한에 가깝고, 약사 B와는 여전히 낮습니다(약사 B가 '위험'을
  더 넓게 씀: 52%).
- 프로그램 판정 분포: 위험 49 · 주의 76 · 비교적 안전 75. 약사가 '안전'이라 했는데 프로그램이 '위험'인 사례 0건, 두 약사보다 높게 본 사례 4건
  — **중등도 신장저하·지방간 같은 가벼운 환자에서 새 규칙의 과다 판정은 나타나지 않았습니다.**
- 두 약사 모두 '위험'인 65건: 프로그램 위험 40 · 주의 18 · 안전 7. 1차를 보고 고친 규칙의 효과는 새 사례에서도 있었지만(민감도 +14~16%p),
  개발 세트에서의 97% / 76%에는 크게 못 미칩니다 — 과적합을 피해 독립 세트로 다시 잰 이유입니다.
- 두 약사 모두 '위험'인데 낮게 본 25건의 원인: QT 연장 환자에게 QT 연장 약 6('부정맥·QT연장'이 한 항목이라 '주의'로만 판정), 간질환
  (둘록세틴·이소트레티노인·발프로산은 허가사항상 간질환 전반 금기인데 간경변에만 적용, 피오글리타존·리팜피신 누락) 7, 중증 신장(메토트렉세이트·
  아시트레틴 누락) 4, 임신(타목시펜·이트라코나졸·아미오다론 누락) 5, 같은 계열 중복(ARB+ARB, DPP-4+DPP-4)을 '주의'로 둠 2, 기타 1.

## 6. 해석과 다음 단계
- 이 200건으로 규칙을 고치면 같은 200건의 점수는 당연히 오릅니다(과적합). 고친 뒤의 성능은 **새 사례**로 다시 검수해야 정직한 수치입니다.
- 약사 판정의 '위험'에는 '처방 변경·용량 조절이 꼭 필요'가 포함되어(아픽사반 감량 기준 등) 용량 정보 없이 판정하는 프로그램보다 넓습니다.
- 두 약사의 '위험' 비율 차이(35% vs 54%)가 커서, 약사 사이의 기준 차이도 결과에 영향을 줍니다.
