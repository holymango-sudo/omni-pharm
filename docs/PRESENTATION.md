# OMNI-PHARM 3분 시연 대본

> 준비: `start_servers.ps1` 실행 → 브라우저 전체화면(F11, 1920×1080 권장) → 🔊 켜기.
> 시연 직전 한 번 "타이레놀 + 와파린"을 돌려 LLM을 VRAM에 올려 두면 첫 응답이 즉시 나옵니다.

---

### 0:00 – 0:20 | 문제 제기
"65세 이상 환자의 절반은 5개 이상의 약을 동시에 복용합니다. 기존 상호작용 검색기는 '약 A와 약 B가 상호작용한다'는 **문서 검색**에 그칩니다.
하지만 같은 두 약이라도 **간이 망가진 74세 환자**와 **건강한 35세**에게는 위험이 전혀 다릅니다.
OMNI-PHARM은 환자 상태와 분자 구조를 **동시에** 분석하는 로컬 AI 시스템입니다."

### 0:20 – 0:50 | ① 환자 프로파일링 (왼쪽 패널)
- 프리셋 **[간경변 고령]** 클릭 → AST 128 / ALT 96 / 빌리루빈 3.4 → 간 게이지가 붉게 **"Hy's law 범위"**
- 크레아티닌 슬라이더를 움직이면 eGFR 게이지가 **CKD-EPI 2021** 공식으로 실시간 재계산되는 것을 보여줌
- "입력된 수치는 표준 임상 공식으로 신장·간 기능 등급으로 바뀌어, 실제 FDA 이상사례 보고 **수백만 건**으로 학습한 환자 모델에 들어갑니다."

### 0:50 – 1:20 | ② 3D 약물 합성 뷰 (중앙)
- 검색창에 **"타이레놀"**, **"와파린"** 입력 → 실제 PubChem 구조로 계산한 3D 분자가 스폰되어 회전
- (선택) **SMILES 직접 입력** 시연: "세상에 없는 구조도 그래프 신경망이 원자·결합 단위로 읽어 예측합니다."
  - 예: `CC(C)(C)c1ccc(cc1)C(=O)NCCN1CCOCC1` → 라벨에 보라색 테두리 **신규 구조**

### 1:20 – 1:40 | ③ 시뮬레이션 인게이지
- **[▶ 예측 시작]** → 두 분자가 충돌, 섬광과 함께 데이터 입자가 오른쪽 패널로 쏟아짐
- 사이렌 점등: **"[경고: 위장관 및 혈액 — 위장관 출혈 · INR 상승 위험 (환자 맞춤 확률 x%, 일반 보고 대비 ×N)]"**
- 인체 맵에서 해당 장기가 붉게 점멸, 오른쪽에 이상반응별 막대(흰 눈금 = 일반 환자 기준선)
- 2초 뒤 중앙이 **홀로그램 인체**로 전환 — 약별 색 입자가 위 → 장 → 간 → 심장 → 표적 → 문제 장기 → 콩팥으로 이동.
  임팩트가 가장 큰 조합은 **[팍스로비드 + 심바스타틴]**: ③ 간 단계에서 CYP3A4 고리가 🔒 빨갛게 잠기고 노란 심바스타틴 입자가 쌓임 →
  ④ 혈중 농도 ▲ → ⑥ 허벅지 근육이 빨갛게 깜박이며 "횡문근융해" — "판정 근거를 그대로 몸에 배치한 것이라, 근거 없는 장면은 나오지 않습니다."

### 1:40 – 2:20 | ④ AI 리포트 (실시간 타이핑)
- 로컬 LLM이 소견서를 토큰 단위로 타이핑 — "인터넷 연결 없이 이 PC의 RTX 5070 Ti에서 생성됩니다."
- **[상세 근거]** 클릭 → 근거 3층 구조 강조
  1. **FDA 허가 라벨 원문** (예: 와파린 라벨의 상호작용 항목)
  2. **실제 병용 보고 신호** (TWOSIDES, PRR ≥ 2)
  3. **AI 구조 예측** (GNN + 분자지문 앙상블)
- "AI는 문서를 대체하지 않고, 문서가 없는 곳을 채웁니다. 근거의 종류를 절대 섞지 않습니다."

### 2:20 – 2:50 | ⑤ 학술적 깊이 — [모델 검증] 탭
- **미래 시점 검증**: 과거 보고로 학습 → 최근 4분기 보고로 평가 (시간 누수 없음)
- **처음 보는 약물 검증**: 학습에서 완전히 제외한 약물로 평가 — "신약에 대한 현실적인 성능"
- **환자 요인 민감도 표**: 같은 약에서 신장질환만 켜면 신장 위험 ×1.4, 심장질환은 심장 위험 ×2 — "모델이 의학적으로 타당한 환자 효과를 데이터에서 스스로 학습"
- **Ablation**: 환자 정보를 뺀 모델 대비 성능 비교

### 2:50 – 3:00 | 마무리
"7800X3D·RTX 5070 Ti 한 대, 외부 서버 0개. 약물 1,829종, FDA 이상사례 보고 1,128만 건, 예측 수십 ms.
OMNI-PHARM은 **'이 환자에게' 위험한 조합**을 찾아냅니다."

## 예상 질문 대비

| 질문 | 답변 요지 |
|---|---|
| 확률 x%가 낮아 보인다 | FAERS는 '이상사례가 보고된 사람들' 데이터라 개별 이상반응의 기본 비율이 0.2~3%. 중요한 건 **기준 대비 배수**와 **표준 환자 대비 배수** |
| 인과관계인가? | 아니오. 보고 기반 연관성. 그래서 FDA 라벨(문서화된 사실)을 최상위 근거로 별도 표시 |
| 신약 성능이 낮지 않나? | 처음 보는 약물 AUROC가 기존 조합보다 낮은 것은 정상이며 숨기지 않고 공개. 무작위(0.5)보다 유의하게 높음 |
| LLM 환각은? | 근거 JSON만 입력, 용량·대체약 이름 생성 금지 규칙, 규칙 준수가 가장 좋은 모델 채택, LLM 장애 시 규칙 기반 리포트 |
| 왜 Neo4j/PostgreSQL을 안 썼나? | 읽기 전용 수백 MB 데이터 — 메모리 인덱스가 더 빠르고 시연 장애 지점이 줄어듦 |
| 의료기기인가? | 인허가 받지 않은 연구·교육용 의사결정 보조 도구. 화면 하단에 상시 고지 |
