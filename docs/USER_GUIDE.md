# OMNI-PHARM 사용 설명서 (일반 사용자용)

함께 먹는 약이 **이 사람에게** 안전한지 확인하는 프로그램입니다. 한국·미국·캐나다·유럽·프랑스·일본 약 11만여 개 제품과
성분명을 알아봅니다.

> ⚠️ 참고용 도구입니다. 약을 끊거나 바꾸기 전에 반드시 의사·약사와 상의하세요.

## 1. 켜고 끄기
| 하고 싶은 일 | 방법 |
|---|---|
| 프로그램 켜기 | 폴더의 **`OMNI-PHARM 실행.bat`** 더블클릭 → 브라우저가 자동으로 열립니다 (10~20초) |
| 휴대폰·태블릿에서 보기 | **`OMNI-PHARM 네트워크 공유 실행.bat`** → 화면에 나온 `http://192.168.x.x:8000` 주소를 같은 와이파이의 휴대폰 브라우저에 입력 |
| 끄기 | **`OMNI-PHARM 종료.bat`** |

브라우저 주소는 언제나 **http://localhost:8000** 입니다. 창을 닫아도 프로그램은 계속 켜져 있습니다.

## 2. 세 단계로 확인하기
1. **환자 정보 (왼쪽)**
   - 나이·키·몸무게·성별을 맞춥니다.
   - 검사 결과지가 있으면 크레아티닌(신장), AST·ALT·빌리루빈(간)을 넣습니다. 모르면 그대로 두세요.
   - **앓고 있는 병**을 모두 누릅니다(위궤양, 녹내장, 전립선비대, 천식, 임신 등). 목록에 없으면 아래 칸에 직접 적습니다.
   - 맨 위 **약물 처리 능력**이 '좋음/보통/저하/매우 저하'로 바로 바뀝니다.
2. **약 추가 (가운데 아래)**
   - 약 이름을 입력하면 목록이 나옵니다. 정확한 제품을 고르세요.
     - 예: `콜대원`, `타이레놀`, `Tylenol Cold`, `Doliprane`, `ロキソニン`, `와파린`, `warfarin`
   - "어떤 제품인가요?"가 나오면 실제로 가진 제품을 고르세요(성분이 서로 다름).
   - 2개 이상 넣습니다.
   - (권장) 약 이름 옆 **＋용량**을 눌러 **1회 몇 정(포·mL) · 하루 몇 번 · 며칠 · 매일/필요할 때만**을 넣으세요.
     제품의 1정당 성분 함량이 자동으로 들어가 하루 총량이 계산됩니다. 함량 정보가 없는 약은 mg로 직접 넣을 수 있습니다(단일 성분).
     주 1회 먹는 약(메토트렉세이트 등)은 "주 단위로 먹는 약"을 체크하세요.
3. **▶ 예측 시작** — 오른쪽에 결과가 나옵니다.

### 용량을 넣으면 추가로 확인하는 것
- **하루 총량 초과** — 여러 제품에 든 같은 성분을 합쳐서(예: 감기약 + 타이레놀의 아세트아미노펜) 1일 최대량과 비교
- **몸 상태에 맞춘 최대량** — 콩팥 기능(체중 반영), 간 기능, 나이, 성별에 따라 최대량을 낮춰서 비교 (예: 트라마돌, 가바펜틴, 세티리진)
- **함께 먹을 때 줄여야 하는 용량** — 예: 심바스타틴은 암로디핀과 함께면 하루 20mg 이하
- **오래 먹을 때의 위험** — 소염진통제 10일, 코막힘약 7일, 수면제 4주, 위산억제제 8주 이상 등
- **복용 주기 오류** — 주 1회 약을 매일 먹는 경우

## 3. 결과 읽기
| 표시 | 뜻 | 할 일 |
|---|---|---|
| 🔴 **위험** | 함께 먹으면 안 되거나, 같은 성분을 두 번 먹게 되거나, 이 사람의 병에 해로운 약이 있음 | 복용 전 의사·약사와 반드시 상의 |
| 🟠 **주의** | 함께 먹을 수는 있지만 관찰·용량 조절이 필요 | 증상을 살피고 상담 |
| 🔵 **비교적 안전** | 뚜렷한 위험 신호 없음 | 정해진 용법 지키기 |

- **왜 그런가요?** — 이유가 쉬운 말로 나옵니다.
  - 💊 같은 성분 중복, 🔁 같은 계열 중복, 🩺 병 때문에 위험한 약, ⛔📄 허가 문서의 경고, 📈 AI 예측
- **어떻게 해야 하나요?** — 할 일이 나옵니다.
- **이 환자의 병 때문에 더 위험한 약** — "근거 보기"를 누르면 허가 문서 원문을 볼 수 있습니다.
- **인체 그림** — AI가 예측한 장기별 신호입니다. 마우스를 올리면 자세히 보입니다.

### 몸속 이동 화면 (가운데)
예측이 끝나면 가운데 화면이 사람 모양 홀로그램으로 바뀌고, 약이 몸속에서 움직이는 과정을 7단계로 보여 줍니다.
약마다 색이 다르며(아래 색 표시), 단계는 자동으로 넘어갑니다. ⏮ ⏯ ⏭ 버튼이나 단계 이름을 눌러 원하는 곳을 다시 볼 수 있습니다.

| 단계 | 보이는 것 |
|---|---|
| ① 복용·위 | 입 → 위. 우유·칼슘과 엉겨 붙는 약은 위에 뭉쳐 멈춥니다 (흡수 방해) |
| ② 장 흡수 | 장 → 간으로 가는 혈관. 자몽은 장벽 효소를 망가뜨려 약이 더 많이 들어옵니다 |
| ③ 간 대사 | 간 옆의 고리 = 약을 분해하는 효소(CYP). 🔒 빨간 고리 = 다른 약이 효소를 막아 약이 쌓임 |
| ④ 혈류 | 심장 → 온몸. 오른쪽 막대 = 약별 혈중 농도 ▲(올라감)·▼(내려감) |
| ⑤ 표적 결합 | 약이 작용하는 곳(뇌·혈관·관절 등)에 붙는 모습. 같은 곳에 겹치면 주황 경고 |
| ⑥ 문제 발생 | 위험한 장기가 빨강(위험)·주황(주의)으로 깜박이며 이유가 표시됩니다 |
| ⑦ 배출 | 콩팥 → 방광. 콩팥 기능이 떨어지면 약이 콩팥에 쌓이는 모습이 보입니다 |

- 설명 칸 오른쪽에는 단계마다 **분자 확대 화면**(약 분자가 효소·수용체에 붙는 모습), **혈중 농도 곡선**(점선 = 그 약만 먹을 때,
  실선 = 이 조합·이 몸 상태, 빨간 띠 = 독성 범위 — 개념도), **기전 경로**(원인 → 기전 → 결과 → 근거)가 나옵니다.
- 왼쪽 위 **⏱ 복용 후 경과 시간**은 각 단계가 약을 먹고 얼마 뒤에 일어나는지 보여 줍니다(예: '복용 후 1시간 50분 — 최고 혈중 농도').
  설명 칸의 시간 눈금(0 · 1시간 · 1일 · 1주)에서 지금 단계의 시간대와 '최고농도'·'97% 배출' 시점을 볼 수 있습니다.
  시간은 FDA 허가 라벨의 약동학 수치(약마다 다름)로 계산하며, 함께 먹은 약 때문에 늦게 배출되면 그만큼 길어집니다. 실제 시간은 사람마다 다릅니다.
- 화면 오른쪽 위 시계는 **현재 날짜와 시각**입니다(복용 후 시간과는 별개).
- 농도 곡선 칸의 **1회 복용 / 반복 복용** 버튼: 반복 복용은 매일 먹을 때 며칠에 걸쳐 농도가 쌓이는 모습(정상상태)과, 함께 먹은 약 때문에 더
  쌓이는 정도, '복용 중단' 뒤 빠져나가는 모습을 보여 줍니다. '＋용량'에 하루 횟수·일수를 넣으면 그대로, 안 넣으면 일반적인 간격으로 그립니다.
  문제 단계에서는 '기전 경로 / 반복 복용 농도'를 전환할 수 있습니다.

### 💬 AI 복약 상담 (궁금한 것 물어보기)
- 화면 오른쪽 아래 **💬 AI 복약 상담**을 누르세요(예측 전에도 됩니다). "같이 먹어도 되나요?", "박카스 마셔도 돼요?", "술 한잔은요?",
  "타이레놀 하루 몇 알까지?", "몇 시간 간격을 둬야 해요?"처럼 자유롭게 묻거나 추천 질문을 누르면 됩니다.
- 질문에 **약이나 음식 이름**이 나오면, AI가 그것을 **지금 먹는 약·내 몸 상태와 함께 바로 검사**한 뒤 답합니다. 답 위에
  "🔎 함께 검사함: 박카스디액 · 주의"처럼 무엇을 검사했는지 표시됩니다(이름이 여러 제품이면 검색창 첫 제품 기준).
- 약에 대한 판단은 분석 결과와 방금 검사한 결과(DUR·허가 문서·규칙·용량 기준·약동학)를 근거로 하고, 그 밖의 일반 약·건강 지식이나
  가벼운 대화에도 답합니다(일반 정보로 표시). 마지막 줄에 근거 출처가 표시됩니다.
- 진단·처방은 하지 않으며, 약을 끊거나 바꾸는 것은 의사·약사와 상의하라고 안내합니다. 숨참·과량 복용·심한 알레르기 같은 말이 나오면
  **119·응급실 안내**가 맨 먼저 나옵니다. 대화 내용은 저장되지 않습니다(사용 기록에는 '질문했음'만 남음).

### 🤒 증상으로 약 찾기
- 약 검색 칸 위 **🤒 증상으로 약 찾기** → 증상(발열·몸살, 목 아픔, 콧물, 코막힘, 기침, 가래, 두통, 생리통, 근육통, 치통, 속쓰림, 더부룩함,
  설사, 변비, 두드러기, 불면, 멀미)을 고르고 **찾기**.
- 증상마다 일반의약품 성분과 제품이 나오고, 지금 환자 정보와 이미 넣은 약을 미리 확인해 **적합 / 주의 / 피하세요**와 이유를 보여 줍니다
  (예: 와파린 복용 중 → 이부프로펜 '주의(출혈)', 위궤양 → 소염진통제 '피하세요', 65세 이상 → 졸리는 감기약 '피하세요', 이미 타이레놀 → 아세트아미노펜 '중복').
- 제품 버튼을 누르면 약 목록에 바로 추가됩니다. **▶ 예측 시작**으로 전체 조합을 다시 확인하세요. 증상마다 '병원에 가야 할 때'도 표시됩니다.

### 서방형(오래 가는 약)
- 제품명에 **서방정·서방캡슐·이알·엑스알·ER·XR·SR·CR** 등이 있으면 약 칩에 **서방형** 표시가 붙습니다(장용정은 **장용형**).
- 서방형은 천천히 녹아 최고 농도가 늦게 오고 오래 갑니다. 1일 최대량·1회량·하루 복용 횟수를 서방형 기준으로 따로 점검합니다
  (예: 타이레놀 8시간 이알 1회 2정·하루 3번까지는 정상, 하루 4번이면 경고).
- **쪼개거나 씹거나 부수지 말고 통째로 삼키세요** — 한꺼번에 녹아 과량이 될 수 있습니다.

### 백업
- **`OMNI-PHARM 백업.bat`** 을 누르면 코드 변경 이력과 데이터·모델·설정이 `OMNI-PHARM_backups` 폴더에 저장됩니다.
- SSD 고장에 대비하려면 USB 등 다른 드라이브에도 받아 두세요: `"OMNI-PHARM 백업.bat" -Target E:\OMNI-PHARM_backups`
- 프로그램을 켤 때마다 바뀐 코드는 자동으로 기록됩니다.
- 이 화면은 판정과 **같은 근거**만으로 그려집니다. 빨간 장기는 판정이 '위험'일 때만 나타납니다.
- **✎ 약 추가·수정**(또는 "분자 보기")을 누르면 약 입력 화면으로 돌아가고, **🧍 몸속 이동 보기**로 다시 볼 수 있습니다.

## 4. 출력하기
- **환자용 안내문**: 숫자 없이 큰 글씨로 판정, 이유, 할 일을 담은 안내문을 인쇄하거나 PDF로 저장합니다.
- **전문가 리포트**: 수치와 근거를 모두 담은 리포트입니다.

### 음식·술·담배도 확인하기
약을 하나 이상 넣으면 검색창 아래에 **함께 확인** 버튼이 나옵니다: 🍺 술 · 🍊 자몽주스 · 🥛 우유 · ☕ 커피 · 🥬 녹색채소 · 🚬 흡연.
누르면 약과 함께 판정합니다. 검색창에 "소주", "맥주", "치즈", "시금치", "담배"처럼 입력해도 됩니다.
예) 수면제 + 술 → 위험, 고지혈증약(심바스타틴) + 자몽주스 → 위험, 항생제(시프로플록사신) + 우유 → 2시간 간격, 와파린 + 녹색 채소 → 매일 비슷한 양.

## 5. 자주 묻는 질문
- **약 이름이 안 나와요** → 성분명으로 넣어 보세요(예: `아세트아미노펜+카페인`). 한약·비타민·주사용 바이오의약품·의약외품(박카스 등)은
  허가 문서·규칙으로 평가합니다(화면에 '바이오'·'생약' 표시). 건강기능식품(센트룸 등)은 아직 포함되지 않습니다.
- **'식약처 DUR'은 무엇인가요?** → 약국·병원 처방 시스템이 쓰는 식약처 공식 금기·주의 목록입니다. 병용금기 조합이면 '위험', 나이·임신·고령에 맞지 않는 약이면
  환자 정보에 따라 경고합니다.
- **일본 일반약(パブロン 등)이 안 나와요** → 일본 일반약은 공개된 데이터가 없습니다. 상자에 적힌 성분명을 넣어 주세요.
- **"전문가 보기"는 무엇인가요?** → 의사·약사를 위한 화면입니다. 확률·배수·계산식 값이 추가로 보입니다.
- **개인정보는 안전한가요?** → 입력한 정보는 이 컴퓨터 안에서만 계산되고 저장되지 않습니다. 네트워크 공유를 켤 때는 PIN 설정을 권장합니다(관리자 안내 참고).

## 6. 관리자 설정 (`.env` 파일)
| 설정 | 의미 |
|---|---|
| `OMNIPHARM_ACCESS_PIN=1234` | 네트워크 공유 시 접속할 때 PIN 입력을 요구합니다 |
| `OMNIPHARM_LLM_MODEL=gemma4:12b` | AI 소견서에 쓸 로컬 LLM 모델 |
| `OMNIPHARM_ONLINE_LOOKUP=false` | 인터넷 조회(PubChem)를 끄고 완전히 오프라인으로 씁니다 |
| `OMNIPHARM_COMMERCIAL_SAFE=true` | 상업 배포용: 연구용 라이선스 데이터(TWOSIDES·KEGG) 기능을 끕니다 |

### 사용자 계정 (여러 사람이 함께 쓸 때)
명령 창에서 프로그램 폴더로 이동한 뒤:
```
.venv\Scripts\python.exe scripts\users.py add 관리자이름 --role admin
.venv\Scripts\python.exe scripts\users.py add 홍길동
.venv\Scripts\python.exe scripts\users.py list
```
- 비밀번호는 입력 창에서 받으며 화면에 보이지 않고, 파일에는 복원할 수 없는 해시로만 저장됩니다(`config\users.json`).
- 사용자가 1명이라도 있으면 화면이 처음에 로그인을 요구합니다. 모두 지우면 로그인이 꺼집니다.
- 로그인 5회 실패 시 5분간 잠기고, 로그인은 12시간 유지됩니다.
- 사용 기록: `logs\audit\연-월.jsonl` (누가·언제·어떤 약·판정). 환자 나이·검사값은 기록하지 않습니다.

### 병원 전산(EMR·OCS) 연동
`POST http://서버주소:8000/api/v1/fhir/assess` 에 HL7 FHIR R4 Bundle을 보내면 판정과 FHIR `DetectedIssue` 목록을 돌려줍니다.
읽는 항목: Patient(생년월일·성별), Observation(LOINC 체중 29463-7·키 8302-2·크레아티닌 2160-0·eGFR·AST·ALT·빌리루빈),
Condition(ICD-10/KCD 코드), MedicationRequest/MedicationStatement(약 이름, 1회량·횟수·처방일수). 이름·환자번호는 읽지 않습니다.
계정을 켠 경우 `POST /api/v1/login`으로 받은 토큰을 `Authorization: Bearer <토큰>` 헤더로 보냅니다.
